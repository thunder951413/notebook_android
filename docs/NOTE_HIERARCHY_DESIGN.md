# Android 笔记层级导航

2026-10-11。用户确认 Android 优先，沿用已有跨端关系，采用“笔记库 → 主笔记 → 子笔记”。每篇笔记都可以写内容并继续嵌套。目标是快速定位笔记并清楚显示结构。

## 参考与取舍

- [Notion](https://www.notion.com/help/navigate-with-the-sidebar)：可折叠嵌套页面、最近访问和搜索。采用页面可同时承载正文和子页面的模型，结构入口随时可达。
- [UpNote](https://help.getupnote.com/organize-and-manage-notes/organize-with-notebooks/sub-notebooks)：移动端从当前父级创建子笔记本，父级可调整。借鉴清晰的归属、折叠和就地创建；本项目按确认的模型嵌套笔记。
- [Craft](https://support.craft.do/zh-Hans/introduction/navigation)：分别呈现文档目录与文件夹视图，支持文档收藏和按名称快速打开。区分“正文目录”和“笔记结构”，避免同一个按钮混淆两种层级。
- [Obsidian](https://obsidian.md/help/plugins/graph)：关系图中的线表示笔记链接。我们的结构图用明确的父子关系展示当前位置，先展示局部上下级，避免把引用关系与归属混成一张图。这是基于本项目目标的设计取舍。

## 实施顺序

1. 复用 `parentPageId`、`sortOrder`、`treeUpdatedAt` 和 `movePage`，构造轻量索引，不读完整正文、不改同步协议。非法环、缺失父级和越库关系在显示时降级为根节点，避免笔记消失。
2. 首页和笔记库增加常驻结构入口；树按库分组，使用缩进、连续分支线、子项数量、展开箭头与选中态。点击标题打开正文，点击箭头只展开。
3. 结构面板提供搜索、最近、固定入口。搜索结果显示完整路径与正文摘要并可在树中定位；定位自动展开祖先、滚动并高亮目标。最近／固定仅保存本机导航偏好，数据关系继续跨端同步。
4. 阅读与编辑页面显示可点击路径，并提供结构入口。完整结构树与正文内标题目录分别呈现。
5. 局部结构图显示父级、当前节点、同级和子节点。点击节点切换关注点，打开动作进入同一篇笔记；展示与折叠不修改实际父子关系。
6. 支持就地创建子笔记、移动到另一父级或提升为顶层；移动复用已有禁止循环、私密边界和子树归属处理。对目标展示路径，避免同名笔记误选。

## 验收口径

- 已知标题从结构搜索可直接打开；不知道标题时可沿库和父子关系找到。
- 从搜索、最近或固定入口打开的深层笔记能一键定位到结构树，祖先自动展开。
- 同名笔记通过路径可区分，深层路径不会挤压手机正文；长标题与分支折叠不导致点击目标混淆。
- 父笔记正文、子笔记正文、移动前后 ID 和附件引用均保留。切换视图不修改 Markdown。
- 未解锁私密笔记不出现在普通树、搜索、最近、固定和图中；已删除笔记不混入活动结构。
- 使用虚拟列表和一次索引，避免每行反复扫描全库；至少验证大量节点和深层结构。
- 构建／单元／模拟器回归后安装独立真机预览，保留原正式 Notebook 数据。

## 已完成与验证（2026-10-12）

上述六步均已接入独立 Android 预览包 `0.4.0-ui.4-debug`（10045）。原系统笔记风格保持，层级入口、树、局部图和阅读路径使用同一套数据关系。结构搜索优先完整标题，其次标题前缀、标题词、路径与摘要；最多展示 100 项并提示继续收窄。完整全文搜索仍沿用首页原查询，结构搜索使用轻量摘要。

树使用虚拟列表，深层缩进有上限并标示深度。库、笔记与未分类区采用独立 UI 键命名空间，支持合法但非 UUID 的现有 ID。非法结构只在显示时降级，避免隐式改写同步关系。结构图默认展示局部上下级，直接子项超过 24 时可以转入树查看全部。

实际复现并修复了“移动后退出编辑器，旧草稿把笔记移回原父级”的问题：更晚的树时间优先，正文仍保存；移动推进到子树最大结构时间之后；面板关闭不取消进行中的移动；移动其他笔记不替换当前阅读正文。

最终单元 187 项通过（9 项新增索引回归，含 5,000 个同层节点及 1,500 层深链）；Lint 0 errors／33 warnings。完整深色设备回归 44 项、浅色受影响回归 23 项通过。最后合法 ID／正文摘要细化后的最终包，层级专项深色 12 项、浅色 12 项全部通过。所有清空数据库的测试只使用 API 35 隔离模拟器。

OPPO PMX110 真机检查了完整微信九宫格触摸输入、中文提交搜索、同名路径区分、定位展开、图中关注切换、打开正文、固定／最近和进程重启。独立预览数据库仅 16 篇演示、4 个库；大规模结构验证是索引单元测试，不是万篇真机流畅度测试。固定和最近是本机偏好，层级字段继续走现有跨端同步；生产跨端同步不在本轮实际验收范围。
